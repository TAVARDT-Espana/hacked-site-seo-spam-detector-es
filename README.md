# Detector de Sitios Hackeados y Spam SEO

[![Detector Spam SEO](https://img.shields.io/badge/TAVARDT-Antispam%20SEO-5b3cf5.svg)](https://tools.tavardt.com/es/detector-seo-spam-sitio-hackeado/)
[![Python](https://img.shields.io/badge/Python-3.8%2B-blue.svg)](https://www.python.org/)

Auditoria de seguridad tecnica para deteccion de cloaking condicional, inyeccion encubierta de enlaces de spam y compromiso de reputacion web.

Desarrollado y mantenido por el equipo de respuesta ante incidentes y analisis forense de **TAVARDT**.

***

## Capacidades de Auditoria Forense y Seguridad Web

* **Deteccion de Cloaking Condicional**: Contraste automatizado de respuestas HTTP entre navegadores convencionales y el rastreador Googlebot.
* **Inyeccion de Enlaces y Texto Encubierto**: Localizacion de etiquetas ocultas mediante estilos CSS, iframes invisibles y granjas de enlaces ilicitos.
* **Redirecciones Maliciosas no Autorizadas**: Monitoreo de comportamientos de desvio de trafico dirigidos unicamente a usuarios moviles o motores de busqueda.
* **Indice de Integridad Forense**: Calificacion objetiva de 0 a 100 con directrices de saneamiento perimetral inmediato.

***

## Instalacion y Uso

Requiere Python 3.8 o superior sin dependencias adicionales.

```bash
git clone https://github.com/TAVARDT-Espana/hacked-site-seo-spam-detector-es.git
cd hacked-site-seo-spam-detector-es
python seo_spam_detector.py ejemplo.es
```

Para salida automatizada en formato JSON:

```bash
python seo_spam_detector.py ejemplo.es -json
```
